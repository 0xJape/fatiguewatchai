atigueWatch AI — Project Overview
FatigueWatch AI is a webcam-based system designed to detect possible driver drowsiness during a simulated driving session. The camera captures the participant’s face, and the program analyzes the eye area to determine whether the eyes appear open or closed.

The system tracks how long the participant’s eyes remain closed. If they stay closed beyond a set time, FatigueWatch AI marks the event as Possible Drowsiness, displays a warning, and sounds an alarm. Otherwise, it displays an Alert status. The system can also record detection events and test results so the researchers can review how quickly and consistently it responds.

The project will focus on the basic functions needed for the study:
- Capture the participant’s face using a webcam.
- Detect the face and monitor whether the eyes are open or closed.
- Measure prolonged eye closure as the main sign of possible drowsiness.
- Display the current status: Alert or Possible Drowsiness.
- Provide an on-screen warning and audible alarm when prolonged eye closure is detected.
- Record detection events and response times for later analysis.
- Test the system under the study’s simulated conditions and evaluate its accuracy and consistency.
The system is intended as an experimental prototype, not a replacement for safe driving practices or a certified vehicle safety device. Testing should take place in a controlled simulation setting, not on public roads.

If time allows, an optional emergency alert feature can be added to notify a designated person when a critical event is detected.
